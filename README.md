# HeyNatash — редакционная архитектура

Сайт собирается генератором статических страниц Jekyll на GitHub Pages. Тексты отделены от HTML-разметки.

| Содержимое | Файл |
| --- | --- |
| Главная страница | `_data/home.json` |
| Статья «Хочешь уйти в медтех-стартап?» | `doctor-to-startup/index.md` |
| Таблица в статье | `_data/article_market.json` |
| Общие подписи, автор и меню | `_data/site.json` |
| Заготовка статьи | `medtech-startup/index.md` |
| HTML-шаблоны | `_layouts/`, `_includes/` |
| Оформление и поведение | `styles.css`, `site-nav.js` |

## Работа с контентом

Для новой статьи создайте папку с `index.md`, скопировав YAML-шапку из `doctor-to-startup/index.md`. Измените `title`, `description`, `permalink`, `canonical_path`, даты, напишите Markdown-текст ниже закрывающего `---`. Обновите `sitemap.xml` и ссылки в данных главной, если нужно.

Сохраняются URL `/`, `/doctor-to-startup/`, `/medtech-startup/`. `docs2tech/index.html` — независимый интерактивный прототип, `medbiotech/index.html` — переадресация; их код не переносился в редакционную систему.

Контент-агент должен изменять `*.md` и `_data/*.json`, оформлять pull request и не публиковать изменения самостоятельно. Для изменений шаблонов потребуется отдельная проверка.

Для слияния важны успешная проверка сборки Jekyll и сравнение опубликованного вида главной и статьи.
